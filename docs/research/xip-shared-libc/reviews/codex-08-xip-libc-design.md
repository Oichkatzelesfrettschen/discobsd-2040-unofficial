1. **Blocker -- the comparison omits the proposed alternative.** Claim: “against the 187-block measured saving” ([stream:28](streams/08-xip-libc-design.md:28)). `rg -ni 'position.independent|PIC|relocat|loader'` returned only “validating loader” at line 13. The stream contains zero position-independent-code or relocating-loader measurements. Future XIP timing falsifiers at lines 102-104 also leave runtime advantage unobserved. **Correction:** compare current static binaries, fixed-address XIP libc, and PIC plus exec-time relocation under identical member policy. Record flash, logical Dhara capacity, RAM, relocation storage, loader code and latency, swap traffic, veneers, and workload timing.

2. **Blocker -- the process-length invariant is incomplete.** Claim: “`exec_estab` adds L to the admission total and sets `p_daddr` to the window base” ([stream:47](streams/08-xip-libc-design.md:47)). [`exec_subr.c:475`](sys/kern/exec_subr.c:475) and line 814 derive `p_dsize` and `u_dsize` solely from executable data plus bss. [`kern_mman.c:24`](sys/kern/kern_mman.c:24) computes the break from `p_daddr`; lines 54-58 zero from `p_daddr + u_dsize`. Applying the stated changes can zero live program bytes and omit bytes from swap. **Correction:** define half-open ranges and set both lengths to `L + text + data + bss`; test first growth, shrink, fork, and swap restoration.

3. **Blocker -- the shipping packed loader retains the old base.** Claim: “`exec_aout_check` sets `data.vaddr = base + L`” ([stream:47](streams/08-xip-libc-design.md:47)). [`exec_hsaout.c:127`](sys/arch/rp2040/rp2040/exec_hsaout.c:127) independently validates against `__user_data_start`; lines 168-201 place and expand packed text there. A mask check for flag `0x03` cannot reserve libc RAM. **Correction:** specify shifted validation, placement, ABI matching, accounting, and initialization in both loaders; exercise packed executables with reserved-RAM canaries.

4. **Blocker -- `_end` remains program-specific.** Claim: “`_curbrk = _end` becomes a bss word set by `__libc_init`” ([stream:43](streams/08-xip-libc-design.md:43)). [`sbrk.c:44`](lib/libc/arm/sys/sbrk.c:44) also clamps `brk()` against `_end`; `arm-none-eabi-nm -u sbrk.o` reports `U _end`. **Correction:** initialize separate current-break and minimum-break cells from `crt0x`, replace both references, and test programs with different image ends.

5. **Major -- the N_ABS citation establishes symbol storage, not callable imports.** Claim: board `ld` “already handles N_ABS” ([stream:68](streams/08-xip-libc-design.md:68)). [`ld.c:592`](usr.bin/ld/ld.c:592) converts the resolved relocation to `RABS`; the call handler skips `RABS` at line 634. Lines 642-645 reject Thumb calls outside approximately 4 MiB and generate no veneer, while SRAM-to-XIP spans roughly 256 MiB. **Correction:** implement callable import stubs or linker veneers and an absolute-call fixture. The stream correctly labels native `cc -xip` unproven.

6. **Major -- “187-block measured saving” lacks a stable denominator.** The initial retained rows reproduced `27 480 293 187`. During review, an external writer left the stream hash unchanged (`a17f...a76c0`) but replaced those rows: current union rows produce `28 502 288 214`; whole-archive rows produce `26 475 278 197`. The variants also have different failures and member surfaces. **Correction:** freeze hashes and source/build identities, name the member policy and failed-row denominator, and measure the final float-hook/private-libgcc policy before using one net-benefit figure.

7. **Minor -- the Dhara estimate is high.** Claim: “about 30 to 35 KB logical” ([stream:28](streams/08-xip-libc-design.md:28)). Applying [`journal.c:475`](sys/arch/rp2040/dhara/journal.c:475) and [`map.c:95`](sys/arch/rp2040/dhara/map.c:95) gives `192 blocks -> 989 KiB` and `186 blocks -> 961 KiB`: a predicted 28 KiB loss. **Correction:** state 28 KiB as the formula result and confirm it with rebuilt `flashimg -c`.

The fixed-address concept survives as a plausible investigation. The kernel measurement reproduces 108,726 occupied flash bytes and 22,090 bytes of headroom; the prototype address collides with Dhara; the 48 KiB MPU mapping is arithmetically valid; and every retained relink variant shows substantial partial-corpus savings. The stream does not yet establish a correct complete loader/heap design or demonstrate that fixed-address XIP beats either the current system or PIC with relocation.
