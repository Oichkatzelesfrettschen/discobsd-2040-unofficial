# MATEzinho MATE artwork pack

Nine native 24x24 PNGs and their editable upstream SVG sources are retained
unchanged from mate-desktop/mate-icon-theme at
15df93ae1d5fbea067eb3d9d5d2a8b3b4a5cbec4. provenance.json records each source
path, Git blob identifier and source-byte SHA-256. The package offers LGPLv3
OR CC BY-SA 3.0 in upstream/COPYING; this pack selects CC BY-SA 3.0.

Attribution: MATE icon theme, MATE and GNOME artists listed in upstream/AUTHORS.
Per-work titles, creators and contributors remain in the retained SVG metadata.
Source: https://github.com/mate-desktop/mate-icon-theme/tree/15df93ae1d5fbea067eb3d9d5d2a8b3b4a5cbec4
License: https://creativecommons.org/licenses/by-sa/3.0/ and the enclosed legal text.

The conversion in tools/matezinho/storage.py flattens alpha on an original
MATEzinho dark surface and quantizes pixels to RGB565, then stores each icon
in a padded 2048-byte record. These converted assets remain under CC BY-SA 3.0.
No Mint CSS, SCSS, theme code, logos or MATE implementation code is imported.
The original shell, conversion tools and dark styling use the repository's BSD
3-Clause license; the font remains the existing public-domain Misc-Fixed font.

Distribute this README, provenance.json, LICENSE-CC-BY-SA-3.0.txt, upstream/COPYING
and upstream/AUTHORS with a generated pack. Keep the upstream SVGs and PNGs
with source releases. Attribution for screenshots: "MATE icon theme, MATE/GNOME
contributors (upstream AUTHORS), CC BY-SA 3.0; RGB565 conversion by MATEzinho."
MATEzinho is independent of MATE and Linux Mint.
